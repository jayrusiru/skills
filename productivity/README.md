# Productivity

General workflow tools for AI assistants, not code-specific.

- [just-finish-it](./just-finish-it) — Run a timeboxed autonomous work session that chooses safe defaults for routine questions and stops for high-risk decisions. Use: `Use $just-finish-it for 12 hours to complete this goal: <goal>` (required dependencies: [`grill-me`](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md), [`superpowers`](https://github.com/obra/superpowers))
